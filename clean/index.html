Let Claude clean your Downloads

One prompt. Claude sorts every file into folders and renames it by what's inside. Nothing gets deleted.

The steps

  1. 1

    Open the Claude desktop app. You need a paid plan (Pro and up).

    Get the desktop app ↗
  2. 2

    Click Work in a folder and pick Downloads. Only that folder.

  3. 3

    Paste this prompt:

    Clean my Downloads
    Sort my Downloads into folders by what each file is. Rename every file by what's inside it. Show me the plan first. Don't delete anything, only move.
  4. 4

    Read the plan. If it looks right, say go.

Good to know

  • Still see Chat and Cowork in the message box? Pick Cowork first.
  • Keep the desktop app open while Claude works on your files.
  • Important stuff in there? Try it on a copy of the folder first.
