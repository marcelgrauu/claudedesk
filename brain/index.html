A second brain that files itself

Andrej Karpathy's LLM Wiki idea, with one prompt.

Set it up

  1. 1

    Open Claude Code or Cowork in an empty folder.

  2. 2

    Paste this prompt:

    Turn this folder into my second brain, using Andrej Karpathy's LLM Wiki pattern. Create:
inbox/ where I drop sources (articles, PDFs, notes). Never edit them.
wiki/ your Markdown pages: one per idea, person or topic, linked with [[wikilinks]].
wiki/index.md with every page and a one line summary.
wiki/log.md with a dated line for every change.
CLAUDE.md with these rules, so you follow them every session.
When I say "file it": read each new file in inbox/, create or update every wiki page it touches, link them to related pages, cite the source, update index.md and log.md, then move the source to inbox/done/.
When I ask a question: read index.md first, answer only from the wiki and link the pages you used. Offer to save good answers as new pages.
Never delete anything.
  3. 3

    Drop your first article in inbox/ and say:

    file it

Good to know

  • See it as a graph: open the folder in Obsidian (free) with "Open folder as vault".
  • Needs a paid plan (Pro or higher) for Claude Code or Cowork.
  • Everything stays as plain Markdown files on your computer.
