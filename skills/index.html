5 Claude skills that blew up on GitHub

Free and open source. Paste the commands in Claude Code.

The five

  1. 1

    Unslop

    Makes your AI built website stop looking AI built. Clone it, copy skills/unslop into ~/.claude/skills/, then try the second line.

    git clone https://github.com/heydamir/unslop
    /unslop this dashboard
    GitHub ↗
  2. 2

    MotionSites Web Builder

    40 loved landing page designs and 50+ cinematic videos for Claude to build with. Works in the Claude app too.

    /plugin marketplace add Motionsites-AI/claude-skill
    /plugin install motionsites-web-builder@motionsites
    GitHub ↗
  3. 3

    Floorplan

    A plain English map of your app, plus a health check that catches keys left in your code.

    claude plugin marketplace add haydenschmitty/floorplan
    claude plugin install floorplan@floorplan
    GitHub ↗
  4. 4

    Reanimate

    Films any website animation and rebuilds it in your code until it matches frame by frame.

    npx skills add NiazMorshed2007/reanimate -g -a claude-code
    GitHub ↗
  5. 5

    Teardown

    Ask how a machine works and Claude builds a 3D simulator you can take apart.

    npx skills add elvarofficial/teardown -g -a claude-code
    GitHub ↗

Good to know

  • Easiest way: paste the GitHub link in Claude Code and say install this skill.
  • MotionSites in the Claude app: download the zip from the repo's release, then Customize > Skills > + > Upload a skill, with code execution on.
  • Floorplan: open a new session after installing. Reanimate needs Bun and is not tested on Windows yet.
  • None of them are official from Anthropic.
